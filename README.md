# Ira Toles Family Tree - Genealogy Research Repository

This repository contains genealogy research for the Ira Toles family tree, including ancestors, DNA matches, and research findings.

## Key Files

### Ancestor Records
- **ancestor.md** - Complete list of ancestors by generation
- **my_direct_ancestors.md** - Direct lineage overview with color coding
- **Toles-Johnson-Smith-Bess-Cobb.ged** - GEDCOM genealogy file
- **Ira Toles Family Tree.csv** - Exported family tree data

### DNA Matches
- **dna_matches_cleaned.md** - Cleaned DNA match data
- **maternal_matches.md** - Maternal side DNA matches
- **paternal matches.ipynb** - Paternal side match analysis
- **dna_matches_leads_table.md** - DNA match leads organized by generation

### Research Files
- **gedcom-text.ipynb** - GEDCOM data parsing and analysis
- **LULA_GREEN_RESEARCH.md** - Research findings on Lula/Lulu Green question

## Recent Research Questions

### Q: Do I have a Lula or Lulu Green in my tree?
**Answer:** No. See [LULA_GREEN_RESEARCH.md](LULA_GREEN_RESEARCH.md) for detailed findings.

While there are several individuals named "Lula" (Johnson, Howard, Halbert, Carter) and multiple Green/Greene family members (Annie Lavinia Green, Sandy R Greene, William Green, etc.), there is no person with both the first name Lula/Lulu and surname Green in the documented tree.
