Segment table analysis

Run the Python script to analyze a segment match CSV and produce summary CSVs and a text report.

Requirements:
- Python 3.8+
- pandas (pip install pandas)

Example:

python analyze_segments.py "C:\Users\irato\Downloads\csvsegmatch_.csv" --out-dir "C:\Users\irato\OneDrive\Desktop\genealogy\genealogy-\scripts\out"
