## Usage Guidelines

### Adding New Cases
1. Create a new case file: `{name}_case.md`
2. Include: match details, hypothesis, evidence, next steps
3. Update close_maternal_matches.md if applicable
4. Cross-reference with existing files

### Updating Hypotheses
1. Add new evidence to hypothesis files
2. Update confidence levels based on findings
3. Document research completed and remaining steps
4. Note any changes to conclusions

### Tracking DNA Kits
1. Add to dna_kits_received.md when kit is received
2. Update status as analysis progresses
3. Link to relevant case files

## Research Workflow

```
New DNA Match Discovered
    ↓
Create case file in Research Data/
    ↓
Analyze match patterns and relationships
    ↓
Form hypothesis (if needed)
    ↓
Document evidence and research steps
    ↓
Execute research plan
    ↓
Update files with findings
    ↓
Reach conclusion or continue investigation
```
